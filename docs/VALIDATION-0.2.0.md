# 0.2.0 发布前检查

检查日期：2026-09-30。

- 公开目录独立整理，采用全新 Git 历史；排除原工作区的个人资料、运行目录、网站采集记录、旧安装包和配对文件。
- 默认示例为 `{}`，生成的个人 profile 不受 Git 跟踪。默认读取插件自身的 `profile/profile.json`，空资料阻止模型任务并提示使用 skill。
- 本机专项身份扫描及公开源码扫描通过。短拼音可能与通用代码词汇重合，匹配需结合上下文人工复核；没有把名字替换后的个人履历用作示例。
- Python 单元测试 **127 项通过**，包含四种生成协议、本机 HTTP 请求头与响应解析、Jev 可配置接口、凭据变更、空 profile、skill 工具、资料匹配、来源复核和 bridge 认证。
- `npm test` 的 **21 组浏览器测试命令全部通过**；`test:widgets` 两组通过。覆盖 MV3 扩展加载、控件、手改、草稿保存/恢复、记录绑定、人工接手和最终提交保护；使用独立无头 Edge、虚构页面和本机 fixture。
- Vue 2 / Element UI 控件测试改为读取 npm 开源依赖，不依赖私有下载目录。skill 的 frontmatter 校验通过；格式、文档清单、来源元数据排除和敏感值拒绝均有测试。
- 安装包经过白名单打包和内容检查；即使已执行配对初始化，ZIP 也不含配对 token、配置、实际 profile、日志、依赖或结果。干净解压后首次启动验证空 profile、无已配置凭据和 token 认证。
- `npm audit --omit=dev` 无生产依赖告警。全部依赖审计存在 **2 项 low**：Vue 2 的 parseHTML ReDoS 告警及 Element UI 的传递关联。它们仅是旧组件测试依赖；测试使用 Vue runtime 与固定虚构 render 函数，不使用其模板编译器。生产扩展和 Python bridge 不加载这些包，仍保留告警供贡献者评估。

验证边界：协议测试为本机模拟请求，未调用用户付费 API；没有重新验证任何真实岗位页面或执行新投递。协议支持不代表所有供应商模型/网关均已实测。GitHub CI 会另行在 Ubuntu / Playwright Chromium 环境运行回归。
