# 使用参考

## 首次使用

按 [README 的完整初始化步骤](../README.md#快速开始从安装-skill-到首次填写) 操作：安装 skill → 在自己的终端配置 Jev / LLM → 从本人材料生成 profile → 本地自检 → 固定虚构内容 API 实测 → 启动 bridge → 配对自检 → 浏览器设置页验收。

`python3 scripts/doctor.py` 不联网；`--probe-models` 才调用模型，可能产生少量费用；`--bridge` 验证实际运行服务的认证、版本、profile 路径和有效 API 配置。配置已保存、模型列表能读取、本机自检通过，这三者都不能单独证明完整初始化成功。

profile、API 或资料路径有问题时按 doctor 的待处理项修复；不要重复点击填写来测试缺失配置。插件不会仅因打开弹窗或重载扩展开始填写。不要在有未保存内容时刷新申请页。

## 表单操作

- **开始填写**：填写支持的空白字段，按 profile 增加可识别的经历。已有值默认保留；保留不代表已核对正确。
- **重试待处理**：补充资料、恢复服务或展开控件后使用。资料与页面没变化时反复运行通常无益。
- **停止**：停止当前轮次。正在进行的草稿保存/恢复先完成核验，避免丢弃未保存内容。
- **仅补空白**：处理已有展开草稿，不从头新增一轮记录。
- **恢复草稿**：从扩展本机存储恢复文本备份；所有文件需手动选择，旧附件引用也不会自动重传。
- **记录页面结构**：诊断控件；结果属于本机资料，先脱敏后才用于问题报告。

报告区会按栏目、记录和原因给出人工接手清单。优先处理必填，再处理必填性未知的项目，最后审阅生成文字和可选项。附件上传、声明和最终提交始终由用户完成。

## 更新资料

仅更新资料时向 agent 说明“使用 `$jev-profile` 更新资料”，保留已有 API 配置；更新同一个 `profile/profile.json`；skill 必须对冲突和覆盖作出说明。profile 每个新任务重读，更新后无需重启 bridge。已核验的生成回答另存 `profile/learned-answers.json`，原始证据改变后不再复用。生成回答不能用来证明新的事实。

没有准确日期时保留已有精度。需要把年月补成完整日期时由本人选择；skill 不默认添加补 01 日规则。相同学校/公司下的不同职位保留独立记录，避免跨经历错填。

## 更新插件

结束当前轮次，替换代码。后端更新后重启 bridge，前端更新后在浏览器扩展管理页点“重新加载”。复制自己的 `profile`、`.runtime/config.json` 或配对配置时，仅在本机私有目录之间操作。配对令牌重建后也需重载扩展。

## 故障排查

| 提示 / 场景 | 操作 |
| --- | --- |
| 本机服务未连接 | 保持 bridge 终端打开；确认监听地址与设置页一致；默认端口 17321 |
| 配对失败 | 启动本目录服务生成 `local-config.js`，重载扩展后在设置页点击“恢复本目录配对”；再检查连接 |
| 自检提示环境配置不同 | 当前终端与服务启动环境不同；检查列出的变量名，从一致的环境重启 bridge，不输出密钥值 |
| profile 为空 | 使用 skill 生成事实；默认 `{}` 只是一份空模板 |
| profile / API 配置无效 | 用校验器 / doctor 定位；JSON 无法读取时先在同一私有目录备份，再修正或重新配置，不把完整文件上传到 Issue |
| HTTP 401 / 403 | 核对 key、账户权限、base URL 和 model ID |
| HTTP 429 / 网络故障 | 等待服务恢复，重试待处理；不连续启动多个轮次 |
| 模型列表不可用 | 核对供应商是否实现 `/models`；不自动换成其他模型 |
| 生成不是有效 JSON | 检查模型是否支持 JSON 输出；不支持 JSON 参数的兼容接口设 `LLM_JSON_MODE=off` |
| iframe 中没有填写 | 设置页只授权所需 iframe 域名，然后重新点击插件 |
| 日期 / 搜索 / 级联无法操作 | 根据人工清单直接手动选择；不把未知控件当作已填写 |
| 保存不成功 | 保留草稿，查看网页校验错误；核对后恢复或手动完成 |

使用其他端口：`python3 -B bridge/server.py --port 17322`，然后重载扩展。使用其他资料路径：`python3 -B bridge/server.py --profile "/path/to/profile.json"`。

移除本机数据时，停止服务后删除 `.runtime/` 和 `profile/` 下的个人文件，并在浏览器中卸载扩展以移除本地草稿。再次安装会生成新的配对配置。
