本版本补齐首次使用流程：安装 skill → 配置自己的 Jev / LLM API → 从真实材料创建 profile → 本地自检与 API 实测 → 服务配对 → 浏览器连接验收。

## 下载与安装

下载下方 Assets 中的 **`jev-resume-autofill-0.2.4.zip`** 并完整解压。安装包包含扩展、本机 bridge、skill 和中文文档；需要 Python 3.9+、桌面 Chrome / Edge 及用户自己的 API 凭据。`SHA256SUMS.txt` 用于校验下载文件。

在插件根目录运行 `python3 scripts/install_skill.py`，再按[中文 README](https://github.com/chanchanpin-official/jev-resume-autofill/blob/v0.2.4/README.md#快速开始从安装-skill-到首次填写)完成初始化。启动 bridge 后，在 `chrome://extensions` 或 `edge://extensions` 启用开发者模式，加载解压目录中的 **`extension/`**。本项目采用加载已解压扩展的方式，安装包不是双击安装的 CRX。

Jev key 从 [TypeSafe 官方控制台](https://console.typesafe.ai/)获取，说明见[官方快速开始](https://docs.typesafe.ai/introduction/quickstart)。LLM 需另配所选供应商的 API。密钥在自己的交互终端输入，不放入聊天、Issue 或浏览器配对框。

## 验证与边界

150 项 Python、25 组浏览器及两组控件测试通过。全新安装测试使用虚构资料、本机模拟 API、真实 bridge 和隔离浏览器；不代表用户自己的服务商账号已通过认证，首次使用仍需运行 `python3 scripts/doctor.py --probe-models`。插件辅助填写，附件、声明和最终提交由本人完成。详见[验收记录](https://github.com/chanchanpin-official/jev-resume-autofill/blob/v0.2.4/docs/VALIDATION-0.2.4.md)。

旧版升级前先备份自己的 profile 和 API 配置；不复制旧配对令牌。更新 skill、重启 bridge、重载新目录的扩展后重新检查连接。
