浏览器回归验证虚构表单与开源 Element UI 控件。通过测试不等于任意企业页面均可自动完成；公开版没有重新执行真实岗位投递。

Jev ≥0.85 时接受资料匹配，0.60–0.85 先补相关上下文重判；事实仍不确定就交人核对，不生成缺失事实。明确的叙述题最多生成一次并修订一次，逐句依据门槛至少 0.90、适配至少 0.85。模型置信度不能作为实际正确率。

默认单轮预算 180 秒，可设 60–600 秒；正在保存或恢复的草稿先完成事务核验。连续 3 个控件操作故障停止本轮；连续两轮新增填写都不足 3 项时建议人工收尾。补资料或展开新内容后仍可重试。

必填性未知的缺失项仍显示在接手清单。明确可选且没有可靠来源的链接可留空。网页已有值只表示“保留”；附件始终手动操作，生成文字仍需人工通读。

欢迎对通用错填风险和多页面可复现问题贡献修复。提交最小虚构复现及回归，不提交真实履历、账户、网页日志或未脱敏截图。
