JEV + LLM / RESUME ASSISTANT

把资料，放到对的空里。

手工选好岗位后，在 Chrome 或 Edge 打开插件弹窗，点击“开始填写”。填完停留在页面，供你检查和提交。

连接本机服务 检查中

在插件目录双击 start.command，保持终端窗口打开。模型密钥和 profile 由本机服务读取。



判断和填写
≥ 高阈值：填写；中间区间：补充上下文再判；仍不足时：事实字段交给人工核对；文字题可由 生成模型 组织已有资料，再交 Jev 复核。


人工接手阈值
默认约3分钟；进行中的保存或草稿恢复会先完成核验。连续3个控件失败会提前交接。连续两轮新增不足3项时，建议人工收尾；补资料或展开新内容后再重试。模型置信度不是正确率。
连续填写
先保留你的手动修改并补填空白，确认栏目保存成功后才新增下一条。多个草稿先在本机备份，再逐条保存并恢复其余内容；中断时可在页面插件面板点击“恢复草稿”。有待处理字段或网页校验未通过时不继续保存；最终投递仍由你完成。


本机配对
这是本机配对令牌，不是 Jev / 生成模型 API key。通常无需修改。Jev 和生成模型的 API、协议和 model 通过 python3 scripts/configure.py 配置。


复杂控件与嵌入页面
自动尝试下拉、搜索建议、级联选择、日期选择、单选、多选和新增经历。所有附件（照片、作品集、附件简历等）由你手动上传，插件保留已有附件。页面拒绝脚本事件或控件无法识别时，会保留待处理清单。跨域 iframe 需额外授权其域名后重新点击插件。


生成内容会标为待审阅。不会自动提交、勾选声明、注册账号或替你选择岗位。
